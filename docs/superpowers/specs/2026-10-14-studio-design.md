# Native data workspace

The native macOS app becomes the operator's ETL workspace, backed by modular TypeScript services. Preserve its menu bar integration, immutable run configuration and process ownership checks. Do not change active collectors or launch enrichment during this implementation. Production content stays out of this engineering chat and Git.

Data sources have explicit configurable registrations, live read-only SQLite counts, independently observed process state, checkpoint age and provenance. Never turn response counts into file counts or describe old checkpoints as live work. Every metric has a definition, observation time, source location and scoped help action. The UI refreshes independently of frozen execution code. Missing, stale and unavailable evidence remain visible.

The explorer pages source tables, displays an actual SQLite record beside its actual JSONL mirror, and reports mirror integrity/missing/limited previews explicitly. Source data is read-only. Editable datasets are separate, versioned local records with stable identities, tags, keywords, summaries, categories, ratings and explicit typed links. Copy selected records into a revision before editing. Deterministic JSON rules provide set/remove/filter/dedupe and validation stages; retain rejected records with diagnostics, pause on failure, and resume after correction. Changes never alter running or staged instances without explicit new revision activation.

Field assistance assembles a small visible metadata packet: product purpose, dataset/run identity, selected field/value, definition, observation age, provenance and applicable controls. A fresh Codex or Claude CLI session handles each initial help request; follow-up belongs only to that session. Exactly three suggested questions are provided. Collection tasks use separate sessions with user instructions and streamed CLI events, with explicit new/reset/branch/compact controls. Do not manufacture native CLI capabilities. Provider availability comes from installed binaries; do not install tools, bypass agent security, or send production contents during engineering. Selected raw record sharing requires an explicit preview/launch action; default help is operational metadata.

All code is TypeScript except existing native SwiftUI views. No new runtime dependencies are required. Persist operator state outside registered source roots. Prefer bounded pagination, prepared read-only SQL, atomic publications and semantic tests. Build a versioned control-plane release independently of immutable processing releases. All changes must pass unit, subprocess integration, synthetic end-to-end tests and native compilation; document actual GUI/live-provider limitations.
