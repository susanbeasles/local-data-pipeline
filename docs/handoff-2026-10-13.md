## Semantic repairs

Knowledge instructions no longer encourage literal placeholder claims such as behavior/fact. Reconciliation distinguishes aliases from interacting distinct components. Connection instructions define source-only evidence, direction, third-party exclusion and scope/version requirements.

The connect runtime first evaluates source presence, then emits the full relation body only when the presence assessment is true. It evaluates each sentence, the complete original context, and reversed sentence context, each in both entity-name orders. All checks run; none stop early. Sentence splitting retains original full context and does not truncate sources. Results are OR-combined and recorded with hashes in phase traces. False yields an empty public edge set. True proceeds with all original spans.

The private generation format places linked before edges/unknowns and actor/target before from/to. Grammar enforces the prior presence verdict, distinct actor/target and matching public direction. Private fields are removed from public output. Public schemas remain unchanged. Internal token allowance was expanded for the private fields rather than taking that allowance away from public analysis.

A library boolean-enum quirk was found: Python booleans were misclassified as numeric enums. Standard boolean parsing plus a lexical consistency parser replaced that private enum use. No validation guard was disabled.
